A compact UCI chess engine written in under 4 KB of pure Python (`engine/main.py`) with alpha-beta search, move ordering, and full rule support (castling, en passant, promotion). Built for the [tiny-chess-01 bounty on make.fun](https://make.fun/bounty/tiny-chess-01).

## Run

```bash
python engine/main.py
```
